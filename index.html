Lector de capturas

Extrae texto de fotos, conversaciones y capturas para facilitar el registro de prospectos inmobiliarios.

Abrir CRM inmobiliario

1. Elige la captura o fotografía

Selecciona una captura de WhatsApp, Messenger o Marketplace, una foto de libreta o cualquier imagen con datos de un prospecto. Para manuscritos, usa buena luz y procura que el texto se vea claro.

Aquí aparecerá tu imagen.

Arrastra sobre una parte para leer solo ese texto. Si no seleccionas un área, se leerá la imagen completa.

Listo para comenzar.

2. Revisar y enviar al CRM

El lector conserva el texto reconocido. No pide productos, cantidades ni importes, y no calcula totales. Revisa y corrige los datos antes de enviarlos.

Privacidad y revisión

El reconocimiento OCR se ejecuta en este dispositivo. Al pulsar Enviar al CRM, el texto pasa a la captura del contacto; revisa los datos y confirma antes de guardarlos.
